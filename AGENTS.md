# Feedrico — instructions for coding agents (Vibe and Claude Code)

Both CLIs load this file. `CLAUDE.md` is the long-form guide — read it in full. Vocabulary
is fixed by `GLOSSARY.md`; the product spec is `docs/spec/v1.md`; hard-to-reverse decisions
live in `docs/adr/`; `docs/personas.md` names who we build for — name personas in issues,
tests and decisions.

## Working in this repo

- The checkout at the repo root is the user's: they run `npm run tauri dev` there, which
  owns port 1420. Agents never edit, commit or run servers in the root checkout; they work
  in a git worktree under `.claude/worktrees/<agent-name>` (git-ignored, see
  `docs/agent-workflow.md`).
- In a worktree, start a UI dev server on another port (`npx vite --port 1430`) and stop it
  afterwards. Never start anything on 1420.
- Rust needs `PATH=/snap/bin:$PATH` on this machine.
- Before every commit, run all checks from `CLAUDE.md`:
  `cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace`, `npm run check && npm test`.
- Conventional Commits, enforced by the commit-msg hook and CI. End every commit message
  with a blank line, the `Generated by …` line and the `Co-Authored-By` trailer of the
  agent that authored the change — see landed commits on `main` (Vibe:
  `Mistral Vibe <noreply@mistral.ai>`, Claude: `noreply@anthropic.com`).
- Batch work: commit locally on the task branch; do not push or open PRs unless asked.
  Write the handoff (status, commit hashes, deviations, open questions, final check output)
  and COMMIT it on the branch — untracked files in a worktree are lost when the worktree is
  reset.

## Skills and docs

- `.agents/skills/` is the shared skill location (both CLIs load it from there).
  CLI-specific skills live in `.claude/skills/` (Claude Code only) and `.vibe/skills/`
  (Vibe only).
- `docs/development.md`: running the app locally. `docs/agent-workflow.md`: the agent
  worktree workflow in full. `docs/accessibility.md`: the WCAG 2.2 AA audit.

## Memory

Vibe has no built-in memory store; its session transcripts stay machine-local under
`~/.vibe/logs/session/`. The repository is the shared memory — this file, `CLAUDE.md` and
`docs/` are what the next agent (Vibe or Claude Code) actually reads.
